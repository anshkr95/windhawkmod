# Windows 11 Glassmorphism Customization Pack 🎨

A curated set of styling configurations for Windows 11 to achieve a premium, unified **glassmorphism (acrylic/blur)** aesthetic across your Start Menu, Notification Center, and Taskbar.

This configuration pack utilizes **Windhawk** and **TranslucentTB** to deliver a sleek visual design with minimal memory footprint (TranslucentTB uses ~1 MB of RAM).

---

## 🌟 Visual Theme Highlights
- **Notification Center**: Elegant glassmorphic background with customizable borders and subtle accent color integration.
- **Start Menu**: Sleek acrylic transparency with premium rounded corners and clean padding.
- **Taskbar**: Completely transparent taskbar blending seamlessly into your desktop background.

---

## 🚀 Setup Instructions

### Step 1: Install the Required Apps
1. **Windhawk**:
   - Download and install the latest version from the [Official Windhawk Website](https://windhawk.net/).
2. **TranslucentTB**:
   - Install **TranslucentTB** from the Microsoft Store to make your taskbar transparent.

---

### Step 2: Apply the Notification Center Styler Config
1. Open **Windhawk**.
2. Go to the **Explore** tab and search for **Windows 11 Notification Center Styler**. Click on **Details**.
3. Under the mod details, navigate to **Advanced** > **Settings** (or Source Code / Mod Settings editor).
4. ⚠️ **Important**: Clear/remove any existing code or default settings inside the configuration input field.
5. Copy the entire contents of [notification_center_styler.json](./notification_center_styler.json) in this repository and paste it into that field.
6. Click **Save Settings** or **Apply** to run the mod.

---

### Step 3: Apply the Start Menu Styler Config
1. Open **Windhawk**.
2. Go to the **Explore** tab and search for **Windows 11 Start Menu Styler**. Click on **Details**.
3. Under the mod details, navigate to **Advanced** > **Settings**.
4. ⚠️ **Important**: Clear/remove any existing code or default settings inside the configuration input field.
5. Copy the entire contents of [start_menu_styler.json](./start_menu_styler.json) in this repository and paste it into that field.
6. Click **Save Settings** or **Apply** to run the mod.

---

## 📂 Repository Contents
