# Windows 11 Glassmorphism Customization Pack 🎨

A curated set of styling configurations for Windows 11 to achieve a premium, unified **glassmorphism (acrylic/blur)** aesthetic across your Start Menu, Notification Center, and Taskbar.

This configuration pack utilizes **Windhawk** and **TranslucentTB** to deliver a sleek visual design with minimal memory footprint.

---

## 🛠️ Prerequisites & Installation

### 1. Windhawk
- **Purpose**: Customizes individual UI elements like the Start Menu and Notification Center.
- **How to Install**: Download and install from the [Official Windhawk Website](https://windhawk.net/).

### 2. TranslucentTB
- **Purpose**: Makes the taskbar fully transparent.
- **Resource Usage**: Extremely lightweight (uses ~1 MB of RAM).
- **How to Install**: Install **TranslucentTB** directly from the Microsoft Store.

---

## 🚀 How to Apply Mod Configurations

Use the guides below to apply customization to each component. This modular setup makes it easy to choose which mods you want to apply.

### 🔹 Windows 11 Notification Center Styler
To style the Notification Center:
1. Open **Windhawk**.
2. Go to the **Explore** tab and search for **Windows 11 Notification Center Styler**, then click **Details**.
3. Under the mod details page, navigate to **Advanced** > **Settings**.
4. ⚠️ **Important**: Remove all earlier code or default text inside the settings box.
5. Copy the entire contents of [`notification_center_styler.json`](./notification_center_styler.json) from this repository and paste it into that settings box.
6. Click **Save Settings** to apply.

---
